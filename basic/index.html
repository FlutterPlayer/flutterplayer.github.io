                                    # 当前版本

                                    Android 内核 AAR 发布在 Maven Central；iOS/macOS xcframework、Windows DLL 和 OpenHarmony HAR 发布在 ijkplayer 的 GitHub Releaseopen in new window。iOS/macOS 的 Swift Package 直接引用该 Release，当前内核版本为 1.2.12。

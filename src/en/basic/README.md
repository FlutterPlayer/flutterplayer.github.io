## Current version

![pub](https://img.shields.io/pub/v/fplayer?label=fplayer&style=flat-square) ![maven](https://img.shields.io/maven-central/v/io.github.flutterplayer/fplayercore?color=blue&style=flat-square&label=Android%20AAR)

The Android kernel AAR is published to Maven Central. The iOS/macOS xcframework, the Windows DLL and the OpenHarmony HAR ship as assets on [ijkplayer's GitHub Releases](https://github.com/FlutterPlayer/ijkplayer/releases). The iOS/macOS Swift Package references that release directly, and the current kernel version is `1.2.12`.
